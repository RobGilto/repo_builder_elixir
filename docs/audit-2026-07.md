## What the audit did NOT flag

Code-level hygiene is excellent — only 3 TODO/FIXME markers across 207 modules,
a strictly enforced typed standard, a 28-line justified Dialyzer ignore file, and
security done properly (redaction before persistence, HMAC + constant-time compare,
AES-256-GCM secrets vault, fail-closed defaults). The debt is structural and
procedural, not sloppy code.

## Remediation phases (see the plan for full checklists)

1. **P0 — Repository hygiene**: feature-scoped commit slices, artifact eviction,
   `.gitignore` hardening, README stat re-sync.
2. **P0 — Ship in-flight specs**: custom-ADW durable observability, ADW-builder
   combo load/delete, non-iso merge-to-trunk.
3. **P1 — Decompose god modules**: per-panel ConsoleLive/components split;
   per-domain orchestrator tools split behind the catalog (tool manifest kept
   byte-stable via snapshot test).
4. **P2 — Retire debt**: `type_check` upgrade/fork so `deps.get` is self-healing;
   Dialyzer-ignore re-audit; regenerate the 24 `adws/` scripts from combos with a
   drift gate.
5. **P2 — Quality-gate plugin tier** + test-naming normalization + tagged
   `:live_acceptance` tier + `ai_docs/architecture-map.md`.
6. **P3 — Deployment**: `mix release`, one deploy target, crash-resume smoke,
   single-operator auth.
